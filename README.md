# 户外鸟巢温度记录 — 设计方案与代码

> 目标：完整记录一个孵化期的巢温波动，电池供电、超低功耗、防水，数据不丢。
> 结论先说：**主推 B 方案（有线探头 + 树干主机）**。A 方案（伪蛋 + 基站）作为备选，只在“必须看到实时温度、且基站能持续供电”时才用。两套代码都给了，编译都通过了（见文末）。

## 1. 两种方案对比

|  | A：伪蛋节点 + 基站 | B：有线探头 + 树干主机（推荐） |
|---|---|---|
| 巢里放什么 | 一颗伪蛋：ESP32-C3 + DS18B20 + 锂电，全套在巢里 | 一根细探头：防水 DS18B20 不锈钢头（直径 6mm），一根 2–3 米细线进巢 |
| 巢外放什么 | 基站 ESP32，5–15 米内持续 BLE 扫描，市电或大电池+太阳能 | 主机 ESP32-C3 + DS3231 + 18650，挂树干防水盒里 |
| 干扰 / 弃巢风险 | 高。伪蛋有重量、有电池、有射频，鸟可能啄、可能弃巢；锂电被啄破有风险 | 低。巢里只有一颗 6mm 金属头 + 细线，重量几乎为零，无射频、无电池、无发热 |
| 数据完整性 | **不能保证完整**。基站断电、超出距离、树叶雨水遮挡都会丢包；蛋内只留最近 48 条（RTC 内存），超了就丢 | **能保证完整**。每 60 秒一笔直接写主机 Flash，不依赖无线链路；无线只在人走近时看实时温度 |
| 功耗 / 续航 | 蛋内电池受蛋尺寸卡死（见 §4）。32mm 蛋只能塞约 100mAh，5 分钟间隔低温折后约 12–14 天，刚够、没余量 | 主机电池不受尺寸限。1 节 18650 3400mAh，60 秒间隔，低温打 5 折仍 >150 天；2 节并联再翻倍 |
| 基站功耗 | 基站不能深睡（要一直扫描），持续 80–120mA，必须市电/太阳能 | 主机深睡，平均 0.37mA；没有“必须常开”的部件 |
| 时间戳 | 蛋内无 RTC，时间由基站收到时打；基站漏收，时间也跟着错 | 主机带 DS3231（CR2032 维持），每笔都是硬件 RTC 时间 |
| 防水 | 蛋壳全密封很难做，合缝、充电口都是漏点 | 主机盒 IP65 + 电缆格兰头；探头本身就是防水不锈钢封装 |
| 取数 | 基站 USB 取数，但蛋还在巢里，换电池要动巢 | 雏鸟离巢后取下主机，USB 接电脑，串口发 `DUMP` 打印全部 CSV |
| 适合 | 想远程实时看温度，且接受“可能丢几天” | **要完整孵化期曲线、要发文章/做分析，选这个** |

一句话：**要“完整”就选 B；要“实时”才考虑 A。** 两个都要的话，B 主记录 + A 只做实时看板（不依赖 A 的数据）。

## 2. 推荐方案 B 的系统

```
鸟巢 ── DS18B20 防水探头 (6mm 不锈钢头, 细线 2-3m) ──> 树干主机盒
                                                         ESP32-C3 SuperMini
                                                         + DS3231 RTC (CR2032)
                                                         + 18650 3400mAh (保护板)
                                                         数据存 LittleFS /nest_log.csv
                                                                    |
                                                    雏鸟离巢后 USB 取数
                                                    串口 DUMP -> nest_log.csv
```

### 2.1 采样间隔：60 秒

亲鸟离巢/回巢一次通常几分钟到几十分钟，60 秒采样能抓住每次波动的起点和终点，14 天共 20,160 笔，约 700KB，Flash 完全放得下。30 秒也可以，续航减半，仍够一个孵化期，没必要。

### 2.2 传感器：DS18B20，不是热敏电阻

- 数字输出，无需 ADC 校准，±0.5°C，10-bit 档 0.25°C 分辨率够用，转换 187ms（12-bit 要 750ms，更费电）。
- 防水探头成品：不锈钢头 + 3 米线，直接买，线从巢边沿垂下、贴着树枝走，用迷彩胶带固定，别悬空晃。
- 探头位置：**紧贴真蛋旁边、巢底垫材表面，感温头朝上贴着蛋侧**，不要埋进垫材里（会低估蛋温），不要悬空（测的是空气）。
- 备选：如果巢很小、6mm 头都嫌大，改用裸片 DS18B20（TO-92，4×5mm）涂导热硅脂后环氧封在探头尖，线用 0.5mm 漆包线三根绞合。裸片方案先在桌上做防水测试（泡水 24 小时读数不变）再上巢。

### 2.3 时间戳：DS3231，不能用 ESP32 内部 RTC

这是 Audiobird 上吃过的亏：ESP32 深睡靠内部 150kHz RC 计时，温度一变就飘，深睡 1 小时能快 30 秒，10 小时能快半小时，一个孵化期下来能漂几个小时，曲线的时间轴就全错了。

做法：

- DS3231 模块 + CR2032，VCC 由 GPIO10 开关供电，醒来读一次就断电，时间靠 CR2032 维持（纽扣电池电流约 3µA，能用几年）。
- 代码只认寄存器读出的合法时间（年 2024–2035、月 1–12 等），全 1 / 全 0 / 越界都判为无 RTC，日志写 `NO_RTC_TIME`，绝不拿深睡时间冒充。
- 对时：上巢前串口发 `T<unix 秒>`，如 `T1792345600`，写完必须读回验证，看到正确时间才算对上，光显示“已同步”不算。
- **ZS-042 模块坑**：常见 ZS-042 自带充电电路，会给不可充电的 CR2032 充电。买无充电版，或拆掉充电电阻，或改用 LIR2032。上电前万用表先确认。

### 2.4 电池与功耗（B 方案，实测为准，桌上先跑 24 小时验证）

| 状态 | 电流 | 时长/周期 | 说明 |
|---|---|---|---|
| 深睡 | 约 13µA | 59.65 秒 | ESP32-C3 深睡约 7µA + 稳压器静态约 5µA + DS18B20 待机 1µA；DS3231 由 CR2032 供电，不计入主电池 |
| 唤醒测温存盘 | 约 62mA | 0.35 秒 | ESP32 工作 + DS18B20 转换 + DS3231 读数 |
| 平均 | **约 0.37mA** | 每 60 秒一周期 | (62mA×0.35s + 0.013mA×59.65s)/60s |
| 18650 3400mAh | 理论 380 天 | 低温打 5 折仍 >150 天 | 0°C 以下容量再打 7–8 折，仍远超 14–21 天孵化期 |

关键点：**不用 SD 卡**。SD 卡每次写入 50–100mA，还怕震动、怕潮。14 天数据才 700KB，直接存内部 Flash（LittleFS），够用又省电。

电池电压采样：100k+100k 分压到 GPIO3，分压比 2.0。**上电前先用万用表量 GPIO3 脚电压，与电池电压/2 对照**，对不上先查线，不要在代码里调系数去凑数——浮空脚会读出几百 mV 的假数。

### 2.5 防水与安装

- 主机盒：ABS 防水盒 IP65，尺寸 100×68×50mm 左右，探头线进线用 PG7 电缆格兰头 + 硅胶密封；盒盖螺丝拧紧，盒内放一小包硅胶干燥剂。
- 盒子挂在巢下方 0.5–1 米的树干背阴面，别挂正上方（雨水顺线流进巢），线留一个 U 形滴水弯。
- 探头线沿树枝走，别绷直，留余量给风吹摆动；线外套一段迷彩缠带，减少鸟的注意。
- 18650 必须带保护板；盒内电池用魔术贴固定，别晃；低温地区（<0°C）给电池包一层薄保温棉，容量能回来 10–20%。

## 3. 备选方案 A 的系统（只在需要实时看时用）

```
伪蛋 (ESP32-C3 + DS18B20 裸片 + 锂电, 每 5 分钟 BLE 广播一次)
        |
        | BLE, 5-15 米, 树叶雨水会缩到 5-10 米
        v
基站 (经典 ESP32, USB 常供电, DS3231 打时间戳, 存 /egg_log.csv)
```

- 蛋内无 RTC、无 SD、无 Wi-Fi，只有最近 48 条在 RTC 内存里，基站漏收即丢，seq 不连续时日志记 `GAP_n_missed`，不要事后补数。
- 基站必须持续供电、持续扫描，不能深睡。充电宝方案要 20000mAh + 太阳能板，且每 2–3 天检查一次。
- 伪蛋模型在 `egg_model/`：参数化脚本 `build_egg.py`，默认 L=32mm、W=23mm、壁厚 1.2mm，输出 `egg_top.stl` + `egg_bottom.stl`，已过水密检查（两个都 watertight）。**先量真蛋再改数**，不要直接打默认尺寸。
- 打印：PETG 或树脂，0.2mm 层高；壳内侧涂环氧密封，合缝处环氧封死；电池用环氧包住再装。PLA 长期泡水会吸水，不推荐。
- 32mm 蛋的尺寸红线：内腔约 20.6mm 宽 × 29.6mm 长，ESP32-C3 SuperMini（22.5×18mm）能塞下，但 500mAh 502030 电池（30×20mm）塞不下，只能用约 100mAh 小锂电，5 分钟间隔低温折后约 12–14 天，刚够、没余量。蛋 ≥40mm 才能用 500mAh，余量才足。

## 4. 功耗与续航核算（A 方案，估算范围，须实测校准）

| 方案 | 间隔 | 平均电流（估算） | 电池 | 理论续航 | 低温打 5 折后 |
|---|---|---|---|---|---|
| B 主机 | 60 秒 | 约 0.37mA | 18650 3400mAh | 约 380 天 | >150 天 |
| A 伪蛋 | 5 分钟 | 约 0.2–0.35mA | 500mAh（≥40mm 蛋） | 约 60–100 天 | 约 30–50 天 |
| A 伪蛋 | 5 分钟 | 约 0.2–0.35mA | 100mAh（32mm 蛋） | 约 12–20 天 | 约 12–14 天，刚够、没余量 |
| A 伪蛋 | 2 分钟 | 约 0.43mA | 500mAh | 约 48 天 | 约 24 天 |

估算假设：BLE 广播平均约 15–25mA × 3 秒 + 测温约 60mA × 0.3 秒。**广播电流与天线、环境有关，数字是范围不是保证**。上巢前桌上跑 24 小时，用 USB 电流表或万用表测平均电流，确认能覆盖孵化期 + 7 天余量再上巢。

## 6. 代码说明

三套代码都在本包里，**零外部库依赖**（DS18B20 的 OneWire 和 DS3231 的读写都是手写的，不用装 OneWire / DallasTemperature / RTClib，Arduino IDE 打开就能编）：

| 文件夹 | 用途 | 编译验证 |
|---|---|---|
| `NestTemp_Host_B/` | B 方案主机：60 秒测温 + DS3231 时间戳 + LittleFS 存盘 + 深睡 | ESP32-C3，core 2.0.17：Flash 1,049,920 字节（80%）、RAM 39,180 字节（11%），通过 |
| `NestTemp_EggNode_A/` | A 方案伪蛋：5 分钟测温 + BLE 广播（seq/温度/电量）+ 深睡 | ESP32-C3，core 2.0.17：Flash 980,780 字节（74%）、RAM 38,884 字节（11%），通过 |
| `NestTemp_Base_A/` | A 方案基站：持续 BLE 扫描 + DS3231 打时间戳 + LittleFS 存盘 | 经典 ESP32，core 2.0.17：Flash 1,161,357 字节（88%）、RAM 39,364 字节（12%），通过 |

串口命令（115200，上电后 2 秒内有效，B 主机 / A 基站通用）：

- `DUMP`：打印全部 CSV 日志
- `T<unix 秒>`：对时，如 `T1792345600`（北京时间 = unix + 8 小时，代码里已算）
- `CLEAR`：清空日志（取数备份后再清）

CSV 格式（B 主机 `/nest_log.csv`）：

```
timestamp,seq,temp_C,batt_V,boot
2026-11-10 08:00:00,1,36.50,4.12,1
2026-11-10 08:01:00,2,36.45,4.12,1
```

温度 `-999` 表示那次读数失败（断线/CRC 错），不要当 0 度画进图里。

B 主机 BLE：按住 GPIO5 的按钮上电/唤醒，进入 120 秒广播，手机装 nRF Connect 能看到实时温度和名字 `NestTemp 36.5C #123`。不按按钮不广播，省电。

## 7. 上巢前检查清单（桌上先过一遍）

1. 通电看串口：RTC 时间合法、温度合理、电池电压与万用表一致（±0.05V 内）。
2. 对时后读回验证，下一行日志时间正确才算对上。
3. 探头放冰水（应为 0.0±0.5°C）和温水（与水银/电子温度计对照 ±0.5°C）各测一次。
4. 深睡电流：万用表串进电池线，深睡时应在 10–30µA 量级；如果几百 µA，查稳压器/模块漏电。
5. 跑 24 小时：日志应为 1,440 笔，时间连续、seq 连续、无 `NO_RTC_TIME`、无 `-999` 扎堆。
6. 防水测试：主机盒盖好后淋水 5 分钟，盒内干燥；探头泡水 24 小时读数不变。
7. 伪蛋（只做 A 时）：蛋壳合缝环氧封死后泡水 24 小时，内部干燥；称重，与真蛋重对比（±10% 内为宜，太重鸟会察觉）。

## 8. 数据怎么看（取回后）

- 用 Excel / Python 画 `timestamp - temp_C` 曲线：孵化期巢温应在 35–40°C 之间波动，亲鸟离巢时温度下滑、回巢后回升，每次离巢是一次 V 形谷。
- 离巢事件：温度连续 3 分钟下降 >1°C 记一次离巢开始，回升到 35°C 以上记回巢；统计每天离巢次数、单次时长、夜间温度。
- 环境对照：最好同时在巢外 1 米处挂一支同样的探头（同一主机再接一根 DS18B20，代码里 ONE_WIRE 可挂多颗，用 ROM 地址区分——本版单探头是刻意简化，先跑通再加第二路），否则分不清“亲鸟离巢降温”还是“冷空气来了”。
- 电池曲线：`batt_V` 从 4.2V 缓慢降到 3.6V 正常；突然跳变说明接触不良或低温掉电。

## 9. 待你确认的三件事（回我一句就行）

1. **鸟种 / 蛋尺寸**：多大蛋？量一下长和宽（mm）。32mm 以下基本只能做 B；40mm 以上 A 才有余量。
2. **巢到能放基站/取数点的距离**：B 方案探头线 2–3 米够不够？主机挂哪棵树干？
3. **孵化期多长**：多少天？（常见雀形目 12–14 天，鸽 17–19 天）用来最后核对电池余量。

这三点不影响先做 B：B 的硬件和代码不依赖蛋尺寸，桌上就能先跑起来。
